# เปรียบเทียบกับตัวอย่าง
อ้างอิงจากภาพหลายช่วงของ https://www.facebook.com/reel/1129160289453903
คลิปทดลอง: เชียงใหม่ — technical proof ไม่ใช่ตอนเผยแพร่
| จุดเปรียบเทียบ | ตัวอย่างที่เห็น | สิ่งที่ทำแล้ว / ข้อจำกัด |
|---|---|---|
| แผนที่จริง | ภูมิประเทศพร้อมชายแดน | ใช้ Natural Earth raster และ vector จริง มี 77 polygon จังหวัดไทย |
| ซูมพื้นที่ | เลื่อนและซูมตามประเด็น | กล้อง eased zoom จากภูมิภาคเข้าจังหวัด; เป็นภาพ 2D ไม่ใช่โลก 3D |
| จังหวัดยกขึ้น | ต้องการตามบรีฟเพิ่มเติมของผู้ใช้ | polygon แยก ยกแนวตั้งพร้อมเงา กรอบแสงสีทอง และคืนตำแหน่ง |
| ภาพพื้นหลัง | ภาพคล้ายดาวเทียม รายละเอียดค่อนข้างสูง | Natural Earth shaded-relief เป็น cartographic terrain รายละเอียดต่ำกว่า ไม่ใช่ภาพดาวเทียมสด |
| ตัวอักษร | ขาว-เหลือง เน้นคำและตัวเลข | มีชื่อจังหวัดและซับไทย ตรวจภาพจากการเรนเดอร์แล้ว; ยังต้องจัด art direction รายตอน |
| เสียง | ยังไม่ได้ฟังเสียงต้นฉบับ | ใช้ skill thai-neural-tts เดิมของผู้ใช้; จึงยังไม่ตัดสินว่าบุคลิกเสียงเหมือนต้นฉบับ |
| เวลาเนื้อเรื่อง | คลิปอธิบายหลายประเด็นและหลายพื้นที่ | เดโมสั้นหนึ่งจังหวัด; ยังไม่แทนการทดสอบคลิปเต็ม 60–90 วินาที |
| ซิงก์เสียง | พื้นที่ตามคำบรรยาย | ใช้เวลาแต่ละวลีจากไฟล์เสียงจริง; จุดพูดชื่อจังหวัดภายในวลียังเป็นค่าประมาณ |
สรุป: ทำเอฟเฟกต์หลักตามบรีฟได้แล้ว แต่ไม่อ้างว่าเหมือนต้นฉบับทั้งหมดหรือให้คะแนนเปอร์เซ็นต์ที่วัดไม่ได้
ก่อนปล่อยตอนจริง: ตรวจบท/ตัวเลข, ซับ, ขอบเขตจังหวัด, จังหวะคำชื่อจังหวัด, ฟังเสียงเต็ม และเปรียบเทียบความลื่นอีกครั้ง
