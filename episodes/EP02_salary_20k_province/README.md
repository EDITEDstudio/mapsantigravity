# EP02: เงินเดือน 20,000 บาท อยู่จังหวัดไหนเหลือเงินเยอะที่สุด?

## 2. จิตวิทยา Engagement (ทำไมคลิปนี้ถึงไวรัล)
- **Relatable 100%:** เงินเดือน 20,000 บาท คือตัวเลขฐานของคนเริ่มทำงาน (First Jobber) และคนวัยทำงานทั่วไปในไทย ทุกคนจินตนาการตามได้ทันที
- **Battle of Living Costs:** คน กทม. จะเข้ามาบ่นเรื่อง "ค่าเดินทางกับค่าหอพักกินไปครึ่งหมื่น" ส่วนคนต่างจังหวัดจะเข้ามาถกเถียงว่า "อยู่ต่างจังหวัดไม่มีขนส่งสาธารณะ ค่าน้ำมันกับค่าซ่อมรถมอเตอร์ไซค์ก็กินเงินไม่แพ้กัน"
- **Shareability:** ถูกแชร์ต่อในกลุ่มหางาน, กลุ่มคนย้ายถิ่นฐาน, กลุ่มมนุษย์เงินเดือน

## 4. แหล่งข้อมูลสถิติจริง (Fact-Check Data)
1. **สำนักงานสถิติแห่งชาติ (NSO):** การสำรวจภาวะเศรษฐกิจและสังคมของครัวเรือน (Household Socio-Economic Survey)
2. **กระทรวงพาณิชย์:** ดัชนีราคาผู้บริโภคระดับจังหวัด (Consumer Price Index: CPI)
3. **สำรวจราคาตลาดอสังหาริมทรัพย์และค่าเช่าหอพัก:** ค่าเฉลี่ยหอพักพนักงาน/First Jobber ในเขตเมืองของแต่ละจังหวัด ปี 2566–2567
