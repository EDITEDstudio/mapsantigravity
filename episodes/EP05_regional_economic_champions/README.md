# EP05: ตัดกรุงเทพฯ ออกไป... จังหวัดไหนคือ "พี่ใหญ่" ตัวจริงของแต่ละภาค?

## 1. ข้อมูลหลัก (Metadata)
- **หมวด:** ภูมิศาสตร์เศรษฐกิจ (Economic Geography) × ศึกประชันจังหวัดระดับภูมิภาค
- **ความยาวเป้าหมาย:** 60–90 วินาที
- **ฟอร์แมต:** 9:16 Vertical (2160x3840 @ 60fps)
- **ฟอนต์:** Kanit ไร้กรอบ
- **เสียงพากย์:** Niwat Neural (คลีน ไม่ใส่ดนตรีพื้นหลัง, -16 LUFS)

## 2. จิตวิทยา Engagement (ทำไมคลิปนี้ถึงไวรัล)
- **Regional Pride:** แฟนคลับและคนท้องถิ่นจะเข้ามาโต้แย้งและเชียร์จังหวัดตัวเองอย่างดุเดือด (เช่น คนโคราช vs คนขอนแก่น, คนเชียงใหม่ vs คนลำพูน, คนสงขลา vs คนสุราษฎร์)
- **Eye-Opening Facts:** คนมักมองว่าเมืองใหญ่สุดคือเมืองที่รวยสุด แต่เมื่อดูตัวเลข GPP ต่อหัว หรือบทบาทอุตสาหกรรม จังหวัดอย่าง "ระยอง" หรือ "ลำพูน" กลับสร้างมูลค่ามหาศาลเกินคาด
- **High Comments on Voting:** คำถามเปิดท้ายคลิปทำให้คนอยากกดคอมเมนต์โหวตจังหวัดตัวเองทันที

## 4. แหล่งข้อมูลสถิติจริง (Fact-Check Data)
1. **สำนักงานสภาพัฒนาการเศรษฐกิจและสังคมแห่งชาติ (สภาพัฒน์ / NESDC):** ผลิตภัณฑ์มวลรวมจังหวัด (Gross Provincial Product: GPP) รายปีล่าสุด
2. **กรมการปกครอง:** จำนวนประชากรตามทะเบียนราษฎร
3. **การนิคมอุตสาหกรรมแห่งประเทศไทย (กนอ.):** สถิตินิคมอุตสาหกรรมภาคเหนือ (ลำพูน) และภาคตะวันออก
