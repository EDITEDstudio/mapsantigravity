# EP03: เปิดแผนที่ 77 จังหวัด: จังหวัดไหนหนี้ครัวเรือนสูงที่สุดในไทย?

## 1. ข้อมูลหลัก (Metadata)
- **หมวด:** ภูมิศาสตร์เศรษฐกิจ (Economic Geography) × สถิติความจริงที่ชวนประหลาดใจ
- **ความยาวเป้าหมาย:** 60–90 วินาที
- **ฟอร์แมต:** 9:16 Vertical (2160x3840 @ 60fps)
- **ฟอนต์:** Kanit ไร้กรอบ พร้อม Heatmap ไล่สี
- **เสียงพากย์:** Niwat Neural (คลีน ไม่ใส่ดนตรีพื้นหลัง, -16 LUFS)

---

## 2. จิตวิทยา Engagement (ทำไมคลิปนี้ถึงไวรัล)
- **Province Curiosity:** "จังหวัดบ้านฉันหนี้เยอะไหม?", "ติดอันดับท็อป 10 หรือเปล่า?" คนดูจะหยุดดูเพื่อมองหาจังหวัดตัวเองบนแผนที่
- **Busting the Myth:** คนส่วนใหญ่คิดว่า กทม. มีหนี้ท่วมหัวที่สุด แต่เมื่อดูอัตราส่วน "หนี้ต่อรายได้ (Debt-to-Income)" จังหวัดเกษตรกรและจังหวัดขนาดเล็กกลับมีสัดส่วนหนี้สูงจนน่าตกใจ
- **Debate on Causes:** ถกเถียงกันในคอมเมนต์ว่าหนี้เกิดจากอะไร (หนี้กู้ทำนา/เกษตร, หนี้นอกระบบ, หนี้ซื้อบ้าน/รถ, หรือหนี้บัตรเครดิต)

## 4. แหล่งข้อมูลสถิติจริง (Fact-Check Data)
1. **ธนาคารแห่งประเทศไทย (BOT):** ข้อมูลสถิติหนี้สินครัวเรือนระดับภูมิภาคและรายงานเสถียรภาพระบบการเงินไทย
2. **สำนักงานสถิติแห่งชาติ (NSO):** การสำรวจภาวะหนี้สินและรายได้ครัวเรือนรายจังหวัด
3. **บริษัท ข้อมูลเครดิตแห่งชาติ (NCB / เครดิตบูโร):** สัดส่วนหนี้เสีย (NPL) และหนี้ค้างชำระตามรายภาค

## 5. การออกแบบโมชั่นแผนที่ (Map Choreography)
- **Visual Style:** แผนที่ 77 จังหวัดแบบ Choropleth (สีเขียวอ่อน = หนี้ต่อรายได้ต่ำกว่า 40%, ส้ม = 40-60%, แดง = เกิน 60%)
- **Waypoints:**
  1. `(0.0s, 100.5, 14.5, 65.0)` - ภาพรวม 77 จังหวัด แอนิเมชันสีวิ่งกระจายตัว
  2. `(5.0s, 100.5, 13.75, 2.5)` - ซูมเจาะ กทม. + แสดงกราฟแท่งหนี้บ้าน
  3. `(25.0s, 102.5, 16.8, 6.0)` - กวาดขึ้นกลุ่มจังหวัดอีสานตอนบน (หนองบัวลำภู/อุดร/ขอนแก่น) แดงเด่น
  4. `(48.0s, 101.2, 12.8, 3.5)` - แพนลงสู่ระยองและชลบุรี
  5. `(70.0s, 100.5, 14.5, 55.0)` - ซูมถอยกว้างเห็นภาพรวมทั้งประเทศ
