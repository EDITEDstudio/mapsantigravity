# EP04: ทำไม "ภูเก็ต" รายได้ท่องเที่ยว 3 แสนล้าน แต่คนพื้นที่บอก "อยู่ยากที่สุด"?

## 1. ข้อมูลหลัก (Metadata)
- **หมวด:** Paradox เศรษฐกิจ (Economic Principles) × ปรากฏการณ์ Dutch Disease & Gentrification
- **ความยาวเป้าหมาย:** 60–90 วินาที
- **ฟอร์แมต:** 9:16 Vertical (2160x3840 @ 60fps)
- **ฟอนต์:** Kanit ไร้กรอบ
- **เสียงพากย์:** Niwat Neural (คลีน ไม่ใส่ดนตรีพื้นหลัง, -16 LUFS)

## 2. จิตวิทยา Engagement (ทำไมคลิปนี้ถึงไวรัล)
- **High Emotion & Debate:** ค่าครองชีพภูเก็ต (ข้าวจานละ 80-120 บาท, ค่าแท็กซี่/รถรับจ้างเที่ยวละ 300-500 บาท, ค่าเช่าคอนโดดอลลาร์) เป็นหัวข้อสนทนาที่ไม่มีวันตกยุค
- **Local vs Tourist Perspective:** คนท้องถิ่นจะเข้ามาเล่าความลำบากที่ค่าแรงขั้นต่ำเท่าเดิม แต่ราคาสินค้าอิงชาวต่างชาติ ส่วนนักท่องเที่ยวจะเข้ามาร่วมยืนยันค่าใช้จ่ายจริง
- **Spatial Storytelling:** การใช้แผนที่เกาะภูเก็ต ลอยตัว 3D เหนือทะเลอันดามัน จะสวยงาม อลังการ และดึงดูดสายตาบนหน้าฟีดอย่างมาก

## 4. แหล่งข้อมูลสถิติจริง (Fact-Check Data)
1. **กระทรวงการท่องเที่ยวและกีฬา:** สถิติรายได้และจำนวนนักท่องเที่ยวจังหวัดภูเก็ตปี 2566–2567
2. **สำนักงานสถิติแห่งชาติ (NSO):** รายได้และการกระจายรายได้ประชากรในจังหวัดภูเก็ต
3. **สำนักงานนโยบายและยุทธศาสตร์การค้า (สนค.):** ดัชนีราคาผู้บริโภคหมวดอาหารและพาหนะในจังหวัดท่องเที่ยว
